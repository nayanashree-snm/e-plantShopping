# Paradise Nursery

## Project Description

Paradise Nursery is an online plant shopping application
that allows customers to explore and purchase beautiful
indoor plants.

## Features

- Attractive landing page
- Multiple plant categories
- Plant images, names and prices
- Add to Cart functionality
- Dynamic shopping cart
- Increase and decrease product quantities
- Remove products from cart
- Automatic price calculation
- Continue Shopping option
- Checkout notification

## Technologies Used

- React.js
- JavaScript
- CSS
- Redux Toolkit
- React Router

## Project Name

Paradise Nursery - Online Plant Shopping Application
